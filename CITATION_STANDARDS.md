# Citation Standards

Market studies must show rigorous provenance. Follow these rules for all reports generated by the agent or by humans.

## Format
- Default style: bracket citations such as `[Source Name, Q3 2025]`.
- Include an **as-of date** or quarter for every factual metric.
- Use dataset identifiers from `SOURCE_REGISTRY.csv` in parentheses when possible, for example `[BLS LAUS (BLS-LAUS), Aug 2025]`.

## Placement
- Every table row classified as `Factual` must include a citation in the table body or in the accompanying footnotes section.
- Narrative paragraphs should cite the most authoritative source at the end of the sentence containing the metric.

## Aggregated Data
- When referencing aggregates derived from paid datasets, cite the dataset and clarify that the value is aggregated (e.g., `[CoStar Analytics (COSTAR-MKT), Q2 2025, Aggregated]`).
- Never include verbatim text from paid reports. Summaries must remain high level.
- For CoStar Market Analytics specifically, only use aggregated metrics and cite them as `[COSTAR-MKT, <as-of>, Aggregated]`. Do not store or surface verbatim CoStar text in indices or reports.

## Source List
Provide a consolidated `Sources` section at the end of each report listing:
1. Dataset name and provider.
2. Access level (public or paid).
3. Retrieval date or API call timestamp.

## Validation
Automated checks in `.github/workflows/validate_report.yml` will scan for:
- Missing citations for factual metrics.
- Paid keywords in narrative sections without aggregation qualifiers.
- Missing as-of dates.

Reports failing validation are rejected until citations comply with this standard.
