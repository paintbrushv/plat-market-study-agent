## Web Search Guidance
- Use web search only for **public** information that complements curated datasets.
- Log every external URL consulted in the provenance payload with access time.
- Do not scrape or summarize gated PDFs; record metadata instead.
- Prioritize official sources (BLS, Census, HUD, Federal Reserve) before blogs or news articles.
- If no authoritative source is found, flag the gap explicitly in the report.
